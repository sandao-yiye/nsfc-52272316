# 网约车与公共交通出行关联机理及协同运行调控技术研究

长安大学国家自然科学基金面上项目（批准号 52272316）成果展示网站。

[打开项目网站](https://sandao-yiye.github.io/nsfc-52272316/)

## 修改文字

1. 用有仓库写入权限的 GitHub 账号登录，打开 [网页正文 index.html](./index.html)，点击铅笔图标。
2. 搜索页面上想修改的文字，例如“韩飞”或论文题目，修改对应段落。
3. 点击 **Commit changes**，提交到 `main` 分支。发布完成后，刷新上面的项目网址即可看到更新。可以在仓库的 **Actions** 标签查看发布进度。

## 替换照片和附件

在下面的文件夹里点击 **Add file → Upload files**，上传同名文件并提交到 `main`。沿用原文件名即可保留网页上的链接。

| 网站内容 | 仓库位置 | 更新时留意 |
| --- | --- | --- |
| 论文成果 | [论文截图](./assets/papers/) | 在 `index.html` 中搜索论文原题，同一条目的 `data-nsfc-p-image` 指向其截图。文件名固定，展示顺序按期刊分区、卷期年份排列。统一图片尺寸为 1800 × 864 像素。修改题名或分区时，请同时核对文末“论文链接”的题录。 |
| 软著成果 | [软件截图](./assets/software/) | 在网页正文搜索“软著成果”可修改软件名称和界面说明。 |
| 研究内容展示 | [研究配图](./assets/research/) | 按研究主题找到相应图表，即可修改图题、说明及论文链接。更换图片时，同时更新图片宽高和图片描述。 |
| 成员介绍 | [教师照片](./assets/members/) | `deng.jpg`、`cheng.jpg`、`wu.jpg`、`han.jpg` 分别对应邓亚娟、程小云、邬娜、韩飞。简介与项目职责可在网页正文修改。 |
| 简介下载 | [项目组主要成员简介与分工.docx](./assets/项目组主要成员简介与分工.docx) | 如同时修改成员信息，请将修订后的同名 Word 上传到 `assets`。 |
| 学术活动 | [活动照片](./assets/activities/) | 在网页正文搜索 TRB、WTC 或 GITSS，可以修改对应会议的介绍、图注和图片描述。有单独高清大图的照片，还要更新 `full` 子目录里的对应文件。 |

## 调整布局

基础版式在 `styles.css`，论文轮播、成员卡片和活动相册样式在 `showcase-update.css`，会议分组和图片放大样式在 `gallery.css`，软著与研究展示样式在 `research.css`，首页标题和移动版导航样式在 `site-theme.css`。网页使用相对路径，可下载整个仓库后在本地打开 `index.html` 预览。
